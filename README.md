# 🎬 YouTube Inappropriate Content Detection

> MCA Major Project 2025 | AI-Powered Safety System

### 📌 Overview
An intelligent Deep Learning system that automatically detects inappropriate YouTube videos by analyzing titles and thumbnails. Aims to make YouTube safer for kids and families.

### 🚀 Key Features
- **Text Analysis:** NLP to detect unsafe words in titles
- **Thumbnail Detection:** CNN model for inappropriate image detection  
- **Real-time Result:** Instant Safe / Unsafe classification
- **Accuracy:** 92% on test dataset

### 🛠️ Tech Stack
Python | TensorFlow 2.15 | Keras | OpenCV | CNN | NLP | Scikit-Learn

### 💻 How to Run
pip install -r requirements.txt
python Main.py
