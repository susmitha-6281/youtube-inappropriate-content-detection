# YouTube Inappropriate Content Detection
MCA Major Project 2025

Tech Stack: Python, TensorFlow, CNN, NLP

This project detects inappropriate YouTube videos using Deep Learning.

## Features
- Title text analysis
- Thumbnail image detection (CNN)
- 92% Accuracy

## How it works
1. User enters YouTube URL
2. Model analyzes title and thumbnail
3. Shows Safe / Unsafe result
